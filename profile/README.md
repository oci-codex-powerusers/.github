# OCI Codex Power Users

This org is a place to contribute repositories built for sharing and collaboration.  

Don't just build a new project in a personal repo - build it in a standard way (We have a skill), then contribute it here. 

For those of you who want to learn and contribute, consider adding to any repo here, build, test, verify, and actually contribute.

## Learnings

* Learn to read code
* Learn to use GitHub for proper contributions
* Set up Codex properly and use it.
